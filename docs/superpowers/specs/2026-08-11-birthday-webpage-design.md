# 生日祝福网页设计文档

日期：2026-08-11
状态：已与用户确认

## 背景

为朋友「流烬燃」（生日 8/11，当天即生日）制作一个生日祝福网页，部署到 GitHub Pages，方便直接通过网址浏览。内容温馨有趣，色调偏暖，包含大量生日祝福与动画。

## 收件人画像

- 昵称：流烬燃（正文统一使用）
- 性格：开朗外向、为人大度、积极乐观
- 爱好：打羽毛球、打台球、喜欢吃蛋糕
- 喜欢 Hello Kitty（卡通可爱风来源）

## 技术路线（方案A，已确认）

- 纯 HTML/CSS/JS 单页沉浸式 H5，零依赖、零构建
- 文件结构：`index.html` / `style.css` / `script.js` / `README.md`
- 字体使用系统圆体栈，无 CDN 依赖
- 部署：用户稍后提供 GitHub 仓库地址，由助手推送并开启 Pages

## 页面结构（7 幕，单页滚动）

1. **开场**：暖粉渐变全屏 + 漂浮爱心/星星 + "戳一下，开始生日派对 🎉"按钮 → 点击触发彩带礼炮 + 爱心雨
2. **主祝福（打字机）**："流烬燃，生日快乐！"逐字打出 + 主祝福语 + SVG 手绘白猫插画（致敬 Hello Kitty，原创不侵权）
3. **今日彩蛋**：今天是 8/11，"今天就是你的生日！"大字特效 + 幽默小彩蛋
4. **蛋糕吹蜡烛**：手绘蛋糕 + 8 根蜡烛（代表 8 月），点击逐根吹灭（火焰消失 + 冒烟），全部熄灭 → 烟花 + "生日快乐"金字
5. **祝福翻卡**：四大分类（暖心篇 / 夸夸篇 / 搞笑篇 / 友情篇）各 10 条，共 40 条；卡片正面分类图案，点击 3D 翻转显示祝福，可连续翻
6. **爱好彩蛋**：羽毛球 + 台球互动小动画，暗藏"爱吃蛋糕"梗
7. **结尾**："感谢遇见流烬燃" + 爱心再次飘落 + 署名"—— 永远的朋友"

## 视觉风格

- 主色板（暖色系）：奶油白 #FFF6EE、蜜桃粉、珊瑚橙、暖黄，糖果色点缀
- 大圆角卡片、柔和阴影、糖果渐变
- Hello Kitty 致敬元素：圆脸白猫 + 蝴蝶结 + 胡须，SVG 手绘

## 内容规划

- 40 条祝福分 4 类，融入人设：开朗外向 / 羽毛球 / 台球 / 爱吃蛋糕
- 主祝福语 + 开场文案 + 结尾文案，走心 + 幽默

## 动画清单

| 动画 | 实现 |
|---|---|
| 开场彩带礼炮 + 爱心雨 | JS 生成 DOM 元素 + CSS 动画 |
| 背景漂浮气球/爱心/星星 | CSS 动画常驻 |
| 打字机 | JS 逐字输出 |
| 蜡烛吹灭 + 冒烟 | 点击交互 + CSS |
| 烟花 | JS + CSS 粒子 |
| 祝福翻卡 | CSS 3D 翻转 |
| 滚动渐入 | IntersectionObserver |

## 成功标准

- 本地双击 index.html 可完整预览，无控制台报错
- 手机 + 桌面自适应
- 内容无错别字，祝福语感情到位
