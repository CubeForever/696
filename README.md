# 🎂 流烬燃的生日网页

为流烬燃精心制作的单页生日祝福 H5，卡通可爱风、暖色调。

## ✨ 页面内容

单页滚动式浏览，共 7 幕，每幕一个惊喜：

| 幕 | 内容 | 交互 |
|---|---|---|
| 开场 | 暖粉渐变 + 漂浮气球/爱心/星星 + Hello Kitty | 点击"开始生日派对"触发彩带礼炮与爱心雨 |
| 主祝福 | "流烬燃，生日快乐！"逐字打字机 + 照片 | 每秒 2 字，打完后逐字波浪弹跳 |
| 今日彩蛋 | "今天就是你的生日！"大字弹跳 + 幽默文案 | 纯浏览 |
| 蛋糕许愿 | 8 根蜡烛的手绘蛋糕 | 点击逐根吹灭（冒烟），全灭触发烟花 |
| 祝福翻卡 | 40 条祝福 × 4 类（暖心/夸夸/搞笑/友情） | 3D 翻卡 + 分类切换 + 下一条 |
| 爱好彩蛋 | 羽毛球 + 台球互动 | 羽球：连续扣杀连击小游戏；台球：一杆进洞动画 |
| 结尾 | 流烬燃照片 + 祝福署名 | 爱心飘落收尾 |

## 🎨 技术栈

- 纯 HTML / CSS / JS，零依赖、零构建
- CSS 变量色板（奶油白 / 蜜桃粉 / 珊瑚橙 / 暖黄），弹性与缓出动画曲线
- IntersectionObserver 滚动渐入，3D transform 翻卡，Canvas 免 JS 粒子（DOM + CSS 动画）

## 📁 文件结构

